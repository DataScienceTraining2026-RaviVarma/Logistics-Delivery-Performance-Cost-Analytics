# Logistics Delivery Performance & Cost Analytics

## Project Description
A comprehensive data analytics solution that converts raw logistics data into meaningful business information by cleaning data, calculating KPIs, generating visualizations, and presenting actionable business insights.

## Technology Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Dashboard:** Streamlit
- **Testing:** Pytest

## Project Structure
Standard modular analytical structure featuring `src` for reusable logic, `app` for the dashboard, `notebooks` for exploratory analysis, and `tests` for validation.

## How to Run
1. **Install dependencies:** `pip install -r requirements.txt`
2. **Run Cleaning Pipeline:** `python run_pipeline.py`
3. **Run Dashboard:** `streamlit run app/streamlit_app.py`
4. **Run Tests:** `pytest tests/test_pipeline.py`
